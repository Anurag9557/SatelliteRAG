SatelliteRAG - setup
====================

Python 3.11 or 3.12. Newer versions often have no matching CUDA wheel.


ONE-TIME SETUP
--------------

1. Virtual environment

       cd SatelliteRAG
       py -3.11 -m venv .venv
       .venv\Scripts\activate

2. PyTorch FIRST, before requirements.txt

   Check what CUDA version the driver reports:

       nvidia-smi

   Install the matching wheel:

       CUDA 12.8   pip install torch --index-url https://download.pytorch.org/whl/cu128
       CUDA 12.1   pip install torch --index-url https://download.pytorch.org/whl/cu121
       CUDA 11.8   pip install torch --index-url https://download.pytorch.org/whl/cu118
       CPU only    pip install torch

   Verify:

       python -c "import torch; print(torch.__version__, torch.cuda.is_available())"

   Must end in +cuXXX and print True.

   Order matters. pip resolves torch against PyPI, which serves CPU-only
   wheels, so installing requirements.txt first pulls the CPU build and a
   later CUDA install has to undo it. torch is deliberately absent from
   requirements.txt for the same reason.

3. Everything else

       pip install -r requirements.txt

4. Embedding model, downloaded once

       python cli.py prefetch minilm-l6

   Everything after this runs offline.

5. Vision model for figure captions (optional but recommended)

       ollama pull qwen2.5vl

   Without it, use --skip-captions and diagrams will not be searchable.

6. LibreOffice, only if any satellite has a legacy .doc file

       https://www.libreoffice.org

   Found automatically once installed. Alternatively, open the .doc and
   save it as .docx by hand.


FIRST RUN
---------

satellites\aditya-l1\ ships with a small public ISRO demo dataset, so
there is something to query right after setup:

    python cli.py build aditya-l1
    python cli.py query aditya-l1 "What are Aditya-L1's science objectives?"

To add another satellite, the folder alone is enough — no config file, no
filenames to type in:

    satellites\chandrayaan-3\documents\   <- make it, copy documents in
    python cli.py build chandrayaan-3

See README.md for: which filenames are recognised, what `build`'s three
stages each do, the three ways to query (one-shot / interactive shell /
a file of questions), chunk-size and embedding-model overrides, and the
full command list.
